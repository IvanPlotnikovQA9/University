# Task Manager

Модуль **Task Manager** предназначен для создания, назначения и контроля выполнения задач в рамках корпоративной информационной системы.

---

## 📌 Описание проекта

Проект реализует базовый функционал управления задачами:
- создание и редактирование задач
- назначение исполнителей
- отслеживание статусов выполнения
- хранение истории изменений и комментариев

Модуль ориентирован на использование в корпоративной среде и интеграцию с существующими сервисами аутентификации.

## 🧩 Основной функционал

- Создание задач с приоритетами и сроками выполнения
- Назначение ответственных пользователей
- Изменение статусов задач
- Просмотр списка задач и фильтрация
- REST API для интеграции с внешними системами

---

## 🛠️ Используемые технологии

- Backend: **Node.js / Java (Spring Boot)**  
- API: **REST, OpenAPI (Swagger)**
- База данных: **PostgreSQL**
- Аутентификация: **JWT / OAuth 2.0**
